# 🚀 Featured Work

### 🤖 RepoMind — Repository-aware AI Developer Tool

> **My main AI systems project.**

RepoMind is evolving into a developer workspace where a repository can be indexed and understood by AI so developers can ask questions against actual code context.

**Current engineering direction:**

- Repository indexing pipeline
- AI-service architecture
- Background indexing with **BullMQ workers**
- **Redis** for queue infrastructure
- PostgreSQL + Prisma
- Better Auth
- Server-side API proxying
- JWT propagation into background workers
- Removing client-controlled identity from AI-service requests
- JWKS-based authentication work

The latest work has focused heavily on **authentication boundaries and worker/service communication**, rather than treating the AI layer as a simple API call.

**Stack:** `Next.js 16` `TypeScript` `PostgreSQL` `Prisma 7` `Redis` `BullMQ` `Better Auth` `Docker` `AI Services`

> 🔒 Main RepoMind repository is private.
